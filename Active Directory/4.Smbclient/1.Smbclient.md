Ahora que tenemos contraseña usamos SMBclient para poder listar recursos SMB con los permisos que hemos obtenido:

smbclient -L //[IP]/ -U [Usuario]


Y despues accedemos al recurso que queramos ver:

smbclient  //[IP]/[Recurso] -U [Usuario]

#PassTheHash 
```
smbclient -L //[IP]/ -U [Usuario] --pw-nt-hash -N --password=[HASH_NTLM]
```
