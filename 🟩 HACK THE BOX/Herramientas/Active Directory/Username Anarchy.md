https://github.com/urbanadventurer/username-anarchy

Es una herramienta para hacer Wordlist de nombres de usuarios una vez hecho OSINT para entornos empresariales:

Uso básico:
```
./username-anarchy [NOMBRE] [APELLIDO]
```
O
```
./username-anarchy -i [ARCHIVO_CON_NOMBRES].txt 
```

Esto lo podremos usar para la herramienta de [[Kerbrute]] o [[Netexec]]
