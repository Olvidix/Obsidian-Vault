/.well-known/ Es una **ruta estándar** usada por servicios web para exponer **información útil**, como configuraciones de seguridad, endpoints de autenticación, o enlaces a políticas. En recon (reconocimiento), puede revelar detalles que normalmente no están visibles.

```
https://example.com/.well-known/security.txt
https://example.com/.well-known/openid-configuration
https://example.com/.well-known/change-password
https://example.com/.well-known/assetlinks.json
https://example.com/.well-known/mta-sts.txt
```
