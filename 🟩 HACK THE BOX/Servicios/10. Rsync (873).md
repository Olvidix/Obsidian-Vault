Es una herramienta rápida y eficiente para copiar archivos local y remotamente. Permite copiar archivos localmente en una máquina y desde/hacia hosts remotos.

```
sudo nmap -sV -p 873 [IP]
```

```
 nc -nv [IP] 873
```

```
rsync -av --list-only rsync://[IP]/dev
```
