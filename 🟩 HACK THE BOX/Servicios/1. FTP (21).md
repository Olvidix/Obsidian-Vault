Conectarse a ftp:
```
ftp [IP]
```

Comandos:
### connect
Establece el host remoto y, opcionalmente, el puerto, para las transferencias de archivos.|
### get
Transfiere un archivo o un conjunto de archivos desde el host remoto al host local.|
### put
Transfiere un archivo o un conjunto de archivos desde el host local al host remoto.|
### quit
Sale del tftp.
### status
Muestra el estado actual de ftp, incluido el modo de transferencia actual (ascii o binario), el estado de la conexión, el valor de tiempo de espera, etc.|
### verbose
Activa o desactiva el modo detallado, que muestra información adicional durante la transferencia de archivos.


## Para descargar todos los archivos de golpe:
No es muy recomendable ya que puede hacer saltar las alarmas ya que es raro que alguien descargue todo el contenido de una sola vez.

```
wget -m --no-passive ftp://[User]:[Pass]@[IP]
```
