# Ejemplos más comúnes
Todos los ejemplos en profundidad los tenemos en [[DIG]]
## NS
```
dig ns [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig ns inlanefreight.htb @10.129.130.122
```
## ANY
```
dig any [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig any inlanefreight.htb @10.129.130.122
```
## AXFR
```
dig axfr [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig axfr internal.inlanefreight.htb @10.129.130.122
```
Sin poner el 'internal' podremos ver los que podemos seleccionar para ponerlos con ese comando

# Attacking DNS
## Obtener todos los registros
Si el servidor permite AXFR sin restricciones, cualquiera puede pedir la zona completa y obtener todos los registros (A, MX, NS, CNAME, PTR, etc.) Ejemplo:
```
dig AXFR @ns1.inlanefreight.htb inlanefreight.htb
```

También podemos usar una herramienta automatizada como [[Fierce]]

## Suplantación de DNS
Lo primero será modificar nuestro archivo de ettercap que es la herramienta que vamos a usar. Tendremos que poner el dominio y los subdominios o posibles que queramos que redirijan a nuestra IP atacante, ya sea un servidor creado con fines maliciosos o nuestra propia maquina con un servidor configurado para ello.

```
Olvidix@htb[/htb]# cat /etc/ettercap/etter.dns

inlanefreight.com      A   192.168.225.110
*.inlanefreight.com    A   192.168.225.110
```
Así es como debería de quedar.
Una vez hecho esto lanzamos nuestra herramienta ettercap escaneamos los hosts y marcamos como objetivos los siguientes:
 - Primero pondremos de Target1 la IP de la maquina víctima objetivo.
 - Después ponemos como Target2 la puerta de enlace predeterminada.
