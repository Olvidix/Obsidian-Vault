## NS
```
dig ns [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig ns inlanefreight.htb @10.129.130.122
```
## ANY
```
dig any [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig any inlanefreight.htb @10.129.130.122
```
## AXFR
```
dig axfr [DOMINIO] @[IP/NOMBRE_DEL_SERVIDOR]
```
Ejemplo:
```
dig axfr internal.inlanefreight.htb @10.129.130.122
```
Sin poner el 'internal' podremos ver los que podemos seleccionar para ponerlos con ese comando
