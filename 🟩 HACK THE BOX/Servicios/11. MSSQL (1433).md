Base de datos de Microsoft.

Para enumerarlo podremos usar nmap:
```
sudo nmap --script ms-sql-info,ms-sql-empty-password,ms-sql-xp-cmdshell,ms-sql-config,ms-sql-ntlm-info,ms-sql-tables,ms-sql-hasdbaccess,ms-sql-dac,ms-sql-dump-hashes --script-args mssql.instance-port=1433,mssql.username=[NOMBRE_DE_USUARIO_POR_DEFECTO_ES_"sa"],mssql.password=,mssql.instance-name=MSSQLSERVER -sV -p 1433 10.129.201.248
```

## Para poder interactuar con la base de datos:
[[Mssqlclient]]

# Una vez dentro:
#### SELECT name FROM sysdatabases;
Para ver las bases de datos disponibles

#### USE [BASE_DE_DATOS];
Para seleccionar una base de datos en concreto

#### SELECT name FROM sys.tables;
Para ver las tablas de esa base de datos

#### SELECT * FROM [TABLA];
Para ver todo lo que tiene una tabla en concreto
