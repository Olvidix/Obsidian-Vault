El servicio de correo que también va de la mano con IMAP/POP3:

Podemos interactuar con el con telnet por ejemplo:
```
telnet [IP] 25
```


#### VRFY
Una vez dentro entre muchos parámetros tenemos uno jugoso "VRFY" para verificar si hay usuarios. Ejemplo:

```
VRFY root
```

Y devolvería algo como:
```
252 2.0.0 root
```
