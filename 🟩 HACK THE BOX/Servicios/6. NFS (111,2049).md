El servicio estándar y ampliamente utilizado para compartir archivos en red en entornos Unix/Linux (y con soporte en Windows)

### Mostramos los recursos disponibles para copiar:
```
sudo showmount -e [IP]
```
Aquí nos dará la ruta del recurso
### Para clonar el recurso accesible:
```
mkdir /tmp/nfs
```
```
sudo mount -t nfs [IP]:[RUTA_DEL_RECURSO] /tmp/nfs -o nolock
```

el `-o nolock` sirve si falla al crearlo debido a que múltiples usuarios estén haciéndolo a la vez

### Para desmontarlo:
```
sudo umount /tmp/nfs
```
