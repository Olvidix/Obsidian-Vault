Base de datos, para acceder a ella:
```
mysql -u [USUARIO] -p[CONTRASEÑA] -h [IP]
```

Una vez dentro podemos ejecutar comandos según la sintaxis SQL:
https://www.w3schools.com/sql/sql_syntax.asp

#### SELECT version();
Para ver la versión

#### SHOW databases;
Para ver las bases de datos

#### USE [BASE_DE_DATOS];
Para seleccionar una base de datos en concreto

#### SHOW tables;
Para ver las tablas de esa base de datos

#### SELECT * FROM [TABLA];
Para ver todo lo que tiene una tabla en concreto

#### SELECT COLUMNS FROM [TABLA];
Para ver las columnas de una tabla en concreto

#### SELECT * FROM [TABLA] WHERE [COLUMNA] = "[STRING_QUE_BUSCAR]";
Para buscar una `string` dentro de la columna de una tabla
