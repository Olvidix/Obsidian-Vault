| **Vulnerabilidad**                                               | **Descripción**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MS08-067`                                                       | MS08-067 fue un parche crítico implementado en diversas revisiones de Windows debido a una falla de SMB. Esta falla facilitó enormemente la infiltración en un host de Windows. Fue tan eficiente que el gusano Conficker la utilizó para infectar todos los hosts vulnerables que encontró. Incluso Stuxnet se aprovechó de esta vulnerabilidad.                                                                                                                                                                                                                                                               |
| `Eternal Blue` smb_ms17_010 shell-session<br>ms17_010_psexec<br> | MS17-010 es un exploit filtrado en el volcado de Shadow Brokers de la NSA. Este exploit se utilizó principalmente en los ciberataques del ransomware WannaCry y NotPetya. Este ataque aprovechó una falla en el protocolo SMB v1 que permitía la ejecución de código. Se cree que EternalBlue infectó más de 200.000 hosts solo en 2017 y sigue siendo una forma común de acceder a un host Windows vulnerable.                                                                                                                                                                                                 |
| `PrintNightmare`                                                 | Una vulnerabilidad de ejecución remota de código en el administrador de trabajos de impresión de Windows. Con credenciales válidas para ese host o un shell con pocos privilegios, se puede instalar una impresora, agregar un controlador que se ejecute automáticamente y otorgar acceso al host a nivel de sistema. Esta vulnerabilidad ha estado afectando a empresas durante 2021. 0xdf escribió una excelente publicación al respecto [aquí](https://0xdf.gitlab.io/2021/07/08/playing-with-printnightmare.html) .                                                                                        |
| `BlueKeep`                                                       | CVE 2019-0708 es una vulnerabilidad en el protocolo RDP de Microsoft que permite la ejecución remota de código. Esta vulnerabilidad aprovechó un canal mal llamado para obtener la ejecución de código, afectando a todas las revisiones de Windows, desde Windows 2000 hasta Server 2008 R2.                                                                                                                                                                                                                                                                                                                   |
| `Sigred`                                                         | La vulnerabilidad CVE 2020-1350 aprovechó una falla en la lectura de registros de recursos SIG por parte del DNS. Es un poco más compleja que las otras vulnerabilidades de esta lista, pero si se ejecuta correctamente, otorgará al atacante privilegios de administrador de dominio, ya que afectará al servidor DNS del dominio, que suele ser el controlador de dominio principal.                                                                                                                                                                                                                         |
| `SeriousSam`                                                     | CVE 2021-36934 explota un problema con la gestión de permisos de Windows en la `C:\Windows\system32\config`carpeta. Antes de solucionar el problema, los usuarios sin privilegios elevados tenían acceso a la base de datos SAM, entre otros archivos. Esto no representa un problema grave, ya que no se puede acceder a los archivos mientras el equipo los usa, pero resulta peligroso al examinar las instantáneas de volumen. Estos mismos errores de privilegio también se producen en los archivos de copia de seguridad, lo que permite a un atacante leer la base de datos SAM y obtener credenciales. |
| `Zerologon`                                                      | CVE 2020-1472 es una vulnerabilidad crítica que explota una falla criptográfica en el Protocolo Remoto de Inicio de Sesión Neto de Active Directory (MS-NRPC) de Microsoft. Permite a los usuarios iniciar sesión en servidores mediante NT LAN Manager (NTLM) e incluso enviar cambios de cuenta a través de este protocolo. El ataque puede ser algo complejo, pero su ejecución es sencilla, ya que un atacante tendría que intentar unas 256 veces la contraseña de una cuenta de computadora antes de encontrar lo que necesita. Esto puede ocurrir en cuestión de segundos.                               |
